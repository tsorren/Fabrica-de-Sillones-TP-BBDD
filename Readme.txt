# Fábrica de Sillones – Modelado y Análisis de Datos

Proyecto académico orientado al diseño y análisis de bases de datos relacionales, desarrollado como
Trabajo Práctico Integrador en la carrera de Ingeniería en Sistemas – UTN FRBA.

## Descripción general

El proyecto consiste en modelar, normalizar y analizar la información de una fábrica de sillones,
partiendo de una base de datos desnormalizada, migrando los datos a un modelo relacional correcto
y construyendo un modelo OLAP para análisis de información relevante para la toma de decisiones.

## Funcionalidades y tareas realizadas

- Análisis de requerimientos de negocio.
- Diseño del modelo entidad–relación normalizado.
- Migración de datos desde una base desnormalizada.
- Diseño de modelo dimensional (OLAP).
- Consultas analíticas para obtención de métricas clave.

## Tecnologías utilizadas

- Miro
- SQL Server

## Modelo de datos

El sistema fue diseñado a partir de un modelo entidad–relación que representa clientes, pedidos,
productos, proveedores y procesos de fabricación.
